# ErdetModLoader

1. Lukk Erdetspill.
2. Høyreklikk spillet i Steam og velg **Administrer → Bla gjennom lokale filer**.
3. Pakk ut hele modloader-ZIP-en i mappa Steam åpner.
4. Dobbeltklikk `INSTALL_MODLOADER.bat` og vent til den er ferdig.
5. Legg mod-ZIP-er i `mods`-mappa. Ikke pakk dem ut.
6. Start spillet vanlig gjennom Steam.

Installereren finner spillet ut fra mappa den ligger i, så Steam kan være installert på hvilken som helst disk.

For å fjerne modloaderen kjører du `REMOVE_MODLOADER.bat`.
